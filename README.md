# Loan Allocation Analysis

## Proje Hakkında

Bu proje, dijital bir finans platformunda gerçekleştirilen kredi başvuru ve kredi tahsis süreçlerinin İş Analizi yaklaşımıyla incelenmesini ve dokümante edilmesini amaçlamaktadır.

Proje kapsamında, bir müşterinin kredi başvurusunun oluşturulmasından kredi tahsis kararının verilmesine kadar olan süreç analiz edilmiştir. İş ihtiyaçları, gereksinimler, iş kuralları, kullanıcı hikayeleri, süreç akışları, veritabanı yapısı, SQL sorguları, test senaryoları ve User Acceptance Testing (UAT) süreçleri ele alınmıştır.

Proje tamamen kurgusal bir senaryo ve örnek veriler üzerinden hazırlanmıştır.

## Proje Amacı

Projenin temel amacı, dijital kredi tahsis sürecinin daha anlaşılır, izlenebilir ve test edilebilir hale getirilmesi için İş Analizi çalışmalarının uygulanmasını göstermektir.

Bu kapsamda;

* İş ihtiyaçlarının belirlenmesi
* Paydaşların ve kapsamın tanımlanması
* Mevcut ve hedef süreçlerin analiz edilmesi
* Fonksiyonel ve fonksiyonel olmayan gereksinimlerin oluşturulması
* İş kurallarının tanımlanması
* User Story ve Acceptance Criteria hazırlanması
* Veritabanı yapısının modellenmesi
* SQL sorgularının oluşturulması
* Front-end ve back-end test senaryolarının hazırlanması
* User Acceptance Testing (UAT) sürecinin planlanması
* Gereksinimlerin testlerle izlenebilirliğinin sağlanması
* Release sürecinin dokümante edilmesi

amaçlanmaktadır.
